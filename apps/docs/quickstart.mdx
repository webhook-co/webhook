---

Create an endpoint, send it a request, and see the captured event — in a few minutes.

<Steps>
  <Step title="Get an API key">
    Create a `whk_` API key in your [dashboard](https://app.webhook.co) and export it:

    ```sh
    export WEBHOOK_API_KEY=whk_your_key_here
    ```
  </Step>
  <Step title="Install an SDK">
    <CodeGroup>

    ```sh npm
    npm install @webhook-co/sdk
    ```

    ```sh pip
    pip install webhook-co
    ```

    ```sh go
    go get github.com/webhook-co/webhook-go
    ```

    </CodeGroup>

    Prefer the command line? `wbhk login` signs you in without an API key — see the [CLI](/authentication#signing-in-from-the-cli).
  </Step>
  <Step title="Create an endpoint">
    Each endpoint has a permanent, signed **ingest URL**. It's shown here and always available in your dashboard.

    <CodeGroup>

    ```ts TypeScript
    import { WebhookClient } from "@webhook-co/sdk";
    
    const webhook = new WebhookClient({ apiKey: process.env.WEBHOOK_API_KEY! });
    const endpoint = await webhook.endpoints.create({ name: "orders-prod" });
    console.log(endpoint.ingestUrl); // https://wbhk.my/whep_...
    ```

    ```python Python
    import os
    from webhook_co import WebhookClient
    
    client = WebhookClient(api_key=os.environ["WEBHOOK_API_KEY"])
    endpoint = client.endpoints.create(name="orders-prod")
    print(endpoint.ingest_url)  # https://wbhk.my/whep_...
    ```

    ```go Go
    client, _ := webhook.NewClient(os.Getenv("WEBHOOK_API_KEY"))
    ep, _ := client.Endpoints.Create(ctx, webhook.EndpointsCreateParams{Name: "orders-prod"})
    fmt.Println(ep.IngestUrl) // https://wbhk.my/whep_...
    ```

    </CodeGroup>
  </Step>
  <Step title="Send it a test event">
    Point a provider at the ingest URL, or just POST to it yourself — no key required to _send_:

    ```sh
    curl -X POST https://wbhk.my/whep_your_token \
      -H "Content-Type: application/json" \
      -d '{"hello":"webhook.co"}'
    ```
  </Step>
  <Step title="Watch it arrive">
    The request is now a captured event. List the endpoint's events — the list auto-paginates:

    <CodeGroup>

    ```ts TypeScript
    for await (const event of webhook.events.list(endpoint.id)) {
      console.log(event.id, event.provider, event.verificationState);
    }
    ```

    ```python Python
    for event in client.events.list(endpoint.id):
        print(event.id, event.provider, event.verification_state)
    ```

    ```sh CLI
    wbhk events list <endpoint-id>
    ```

    </CodeGroup>

    You'll see your `{"hello":"webhook.co"}` event, marked `unattempted` — captured, but unsigned until you [register a provider secret](/guides/verify-inbound-signatures).
  </Step>
</Steps>
