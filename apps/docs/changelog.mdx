Notable changes to the webhook.co API, SDKs, CLI, and documentation. The REST API is versioned in its path (`/v1`); a breaking change ships under a new version rather than mutating this one.

<Update label="2026-07" description="Documentation">
  ## Expanded documentation

A full rebuild of these docs — concepts, guides, per-provider verification for all 142 supported providers, MCP and agent-trigger coverage, a CLI reference, reference pages (the event object, errors, rate limits, pagination, delivery guarantees), and a recipe cookbook. The API reference is generated from the live OpenAPI spec.

</Update>

<Update label="v1" description="API">
  ## API v1

The stable REST API at `https://api.webhook.co/v1`, with official TypeScript, Python, and Go SDKs generated from the OpenAPI contract. Endpoints, inbound verification, deduplication, outbound delivery with retries and signing, replay, agent triggers, and usage — all reachable identically across the CLI, API, dashboard, and MCP.

</Update>
