webhook.co gives you a **free, permanent, signed ingest URL**: point any provider at it and every request is captured — raw bytes first, then verified and deduplicated — where you can inspect it, replay it to localhost with one command, and deliver it onward. It grows with you from a debugging mailbox into a full inbound pipeline (verify → [dedup](/deduplication) → retry → replay) and outbound delivery, and every capability is reachable identically from the **CLI, API, dashboard, and MCP**. Nothing is public unless you make it so.

Signing and verification follow the [Standard Webhooks](https://www.standardwebhooks.com/) spec, on both the receive and send sides.

## The API

The REST API lives at `https://api.webhook.co`. It's a small, predictable surface — every endpoint is described by a machine-readable OpenAPI 3.1 document you can browse in the [**API reference**](/api-reference/endpoints/list-endpoints) or fetch yourself:

```sh
curl https://api.webhook.co/openapi.json
```

That same document generates the SDKs and this site's reference, so they never drift from the running API. Authentication is a `whk_` bearer key — see [authentication](/authentication).

## SDKs

Official, typed SDKs in three languages — each with the same hardening built in: bearer auth, bounded retries with jitter, cursor pagination, idempotency, and secret redaction.
